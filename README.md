# 使用webComponent实现前端微服务

### 使用无界框架当前项目进行重构

## Project setup
```
yarn install
```

### Compiles and hot-reloads for development
```
yarn run serve
```

### Compiles and minifies for webcomponent
```
vue build --target wc-async --name web-app 'src/App.vue'
```

### Lints and fixes files
```
yarn run lint
```
